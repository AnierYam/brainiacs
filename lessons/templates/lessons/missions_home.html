Brainiacs Level 1 – Missions

Select a mission to start learning.

  • Mission 1: Know your Toolbox

    Learn all the tools and fasteners you’ll use to build Pedro.

  • Mission 2: Introduction to Arduino

    Discover what Arduino is, how the IDE works, and upload your first sketches.

  • Mission 3: Building Pedro

    Build Pedro system by system: structure, electronics, and code for each part.

  • Mission 4: Assemble Pedro

    Assemble all systems and combine the code into one full working robot.
